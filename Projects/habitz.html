Project Overview

Habitz is a habit tracking app that allows users to create and track their habits. They can also set scheduled habits to be tracked and also log their progress using daily mood tracking and journaling. The app also has common habbits page where users can just add the habits they like and everything is stored in their dashboard that shows the user's progress and allows them to set goals. The app uses calming colors and makes users feel relaxed and comfortable while using it.
